# Основа — HR-платформа

Сдержанная и практичная HR-платформа для небольшой или средней компании: база сотрудников, онбординг, график отпусков и структура команды. Работает локально в браузере, состояние сохраняется в `localStorage`.

## Разделы

- **Обзор** — сводка по штату, очередь согласования с проверкой пересечений в отделе, активный онбординг и ближайшие отсутствия.
- **Сотрудники** — поиск, фильтры по отделу и статусу, таблица и карточки, выдвижной профиль с вкладками и редактированием данных.
- **Онбординг** — планы адаптации по этапам («День 1», «Первая неделя», «Первый месяц»), фильтр по ответственному и добавление новых задач.
- **Отпуска** — согласование заявок с проверкой пересечений, месячный график с фильтром по отделу и форма новой заявки.
- **Структура** — оргсхема с поиском сотрудников и режим карточек отделов.
- **Поиск (`Ctrl+K`)** — быстрый переход к сотруднику, разделу или действию.

Откройте [index.html](./index.html) в браузере. Кнопка **«Сбросить демо-данные»** возвращает исходное состояние.
