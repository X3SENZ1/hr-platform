# Основа — HR-платформа

Практичная HR-платформа для небольшой или средней компании: база сотрудников, онбординг, график отпусков и структура команды. Приложение переписано с vanilla JS на **React 19 + Vite 8 + TypeScript** с сохранением исходного дизайна и поведения.

## Стек

- **React 19** — компонентный UI и чистые функции рендеринга
- **Vite 8** — dev-сервер и production-сборка
- **TypeScript** — типизация моделей, состояния и форм
- **React Router 7** (`HashRouter`) — маршруты без перезагрузки страницы
- **pnpm** — единственный поддерживаемый менеджер пакетов

## Запуск

```bash
pnpm install
pnpm dev
```

Сборка и просмотр production-версии:

```bash
pnpm build
pnpm preview
```

## Разделы

- **Обзор** — показатели штата, очередь согласования с проверкой пересечений, активный онбординг и ближайшие отсутствия.
- **Сотрудники** — поиск, фильтры, таблица и карточки, профиль с вкладками и редактированием.
- **Онбординг** — планы адаптации по этапам, фильтр по ответственному и добавление задач.
- **Отпуска** — согласование заявок, месячный график отсутствий и форма новой заявки.
- **Структура** — оргсхема с подсветкой сотрудников и режим карточек отделов.
- **Поиск (`Ctrl+K`)** — быстрый переход к сотруднику, разделу или действию.

## Тема и доступность

- Три темы: **светлая**, **тёмная** и **контрастная**. Выбор (`system`, `light`, `dark`, `contrast`) хранится в `localStorage` под ключом `osnova_theme_preference`; акцентный цвет — под `osnova_accent_color`. Тема применяется до отрисовки страницы встроенным скриптом в `index.html`.
- Поддерживаются клавиатура (ссылка «Перейти к основному контенту», стрелки в табах и выпадающих списках, `Escape` для модальных окон), ARIA-роли и контраст текста не ниже 4.5:1.
- Данные хранятся в `localStorage` под ключом `osnova_hr_state_v4`; кнопка «Сбросить демо-данные» возвращает исходное состояние.

## Структура проекта

```
src/
  components/        # shell, фильтры, drawer, модальные окна, UI-примитивы
  data/seed.ts       # демо-данные и шаблоны онбординга
  lib/               # даты, метаданные, бизнес-хелперы, хуки
  state/             # HrContext и ThemeContext
  styles.css         # mobile-first CSS с темами и токенами
  types.ts           # модели данных
  views/             # экраны: обзор, сотрудники, онбординг, отпуска, структура
  App.tsx            # layout и маршруты
  main.tsx           # точка входа
```

## Деплой на GitHub Pages

Соберите проект (`pnpm build`) и опубликуйте содержимое `dist/`. Благодаря `base: './'` и `HashRouter` сборка работает из подпапки репозитория без дополнительной настройки.
