# Основа — HR-платформа

Сдержанная и практичная HR-платформа для небольшой или средней компании: база сотрудников, онбординг, график отпусков и структура команды. Проект переписан с vanilla JS на **React 19 + Vite + TypeScript** с сохранением дизайна и поведения.

Состояние хранится в `localStorage` под ключом `osnova_hr_state_v3`, поэтому данные из предыдущей версии подхватываются автоматически.

## Стек

- **React 19** — компонентный UI
- **Vite 8** — dev-сервер и сборка
- **TypeScript** — типизация моделей и состояния
- **React Router 7** (`HashRouter`) — навигация по разделам, работает на GitHub Pages и любом статическом хостинге

## Запуск

```bash
pnpm install
pnpm dev
```

Альтернатива через npm:

```bash
npm install
npm run dev
```

Сборка и локальный просмотр production-версии:

```bash
pnpm build
pnpm preview
```

## Разделы

- **Обзор** — сводка по штату, очередь согласования с проверкой пересечений в отделе, активный онбординг и ближайшие отсутствия.
- **Сотрудники** — поиск, фильтры по отделу и статусу, таблица и карточки, выдвижной профиль с вкладками и редактированием данных.
- **Онбординг** — планы адаптации по этапам («День 1», «Первая неделя», «Первый месяц»), фильтр по ответственному и добавление новых задач.
- **Отпуска** — согласование заявок с проверкой пересечений, месячный график с фильтром по отделу и форма новой заявки.
- **Структура** — оргсхема с поиском сотрудников и режим карточек отделов.
- **Поиск (`Ctrl+K`)** — быстрый переход к сотруднику, разделу или действию.

Кнопка **«Сбросить демо-данные»** возвращает исходное состояние.

## Структура проекта

```
src/
  components/        # сайдбар, топбар, drawer, модальные окна, UI-примитивы
  data/seed.ts       # демо-данные и шаблоны онбординга
  lib/               # даты, метаданные, бизнес-хелперы
  state/HrContext.tsx# состояние, действия и сохранение в localStorage
  views/             # экраны: обзор, сотрудники, онбординг, отпуска, структура
  App.tsx            # layout и маршруты
  main.tsx           # точка входа
```

## Деплой на GitHub Pages

Соберите проект (`pnpm build`) и опубликуйте содержимое `dist/` в ветке `gh-pages` либо включите GitHub Actions. Благодаря `base: './'` и `HashRouter` сборка корректно работает из подпапки репозитория без дополнительной настройки.
